# 模組類型：公司

> 共用的部分（資料讀取、編輯頁框架、sidebar、選擇器、條件清單、輸出規則）見 [主程式規格](../mod_builder.md)。
> 標示 **〔初版做法〕** 的內容是初版實作時採用的做法，請確認後保留或修改。

可以新增公司，也可以修改、覆蓋現有的公司。狀態：初版已實作。

## 1. 遊戲中的結構

公司定義在 `common/company_types/`，一間公司一個定義：

| 欄位 | 內容 |
| --- | --- |
| `icon`、`background` | 圖示與背景 |
| `category`、`flavored_company` | 所有者類別；是否為特色（歷史）公司 |
| `building_types`、`extension_building_types` | 經營的建築類型；之後可透過特許加入的建築 |
| `possible_prestige_goods`、`prestige_goods_trigger` | 可生產的名貴商品，以及它的條件（原版只用來顯示提示） |
| `prosperity_modifier` | 繁榮時給的修正 |
| `preferred_headquarters` | 優先設立總部的地域 |
| `potential`、`attainable`、`possible`、`can_establish_in` | 顯示、可達成、建立條件，以及建築所在地區 |
| `ai_will_do`、`ai_weight`、`ai_construction_targets` | AI 建立條件、權重、建造目標 |

名稱的翻譯鍵就是公司代碼。工具不認得的欄位原樣保留在「進階」的腳本裡。

## 2. 資料

| 資料 | 用途 | 來源位置 |
| --- | --- | --- |
| 公司 | 右欄的現有公司清單 | `common/company_types/` |
| 公司圖示與背景 | 圖片選項 | `gfx/interface/icons/company_icons/`（加上公司實際引用的路徑） |

其他用到的共用資料：buff / debuff、產業、名貴商品、科技、國家、文化、州、戰略區域、地圖。

〔初版做法〕公司會記錄**所有**定義或修改過它的來源（覆蓋、INJECT 都算），以及每個來源載入後的版本（INJECT 的版本是合併後的結果）。

## 3. 畫面

| Sidebar | 預覽欄 | 編輯區 | 右欄 |
| --- | --- | --- | --- |
| 模組內容（分類「公司」） | 正在編輯的公司 | 各種選項 | 目前所有的公司（可篩選） |

### 3.1 預覽欄：正在編輯的公司

顯示目前正在製作的這一間公司的設定摘要，編輯區的選項一改，這裡就跟著更新。

〔初版做法〕

- 顯示公司名稱、圖示、產業、加成、總部、條件與 AI 摘要、各語言是否已填。
- 預覽欄標題旁是「保存」，最下面是「新公司」（開始一間空白的公司）；刪除在 sidebar（✕）。
- 尚未填完的必填項目在這裡提示（錯誤會擋住儲存，提醒不會）。

### 3.2 編輯區：各種選項

〔初版做法〕可設定的項目：

| 項目 | 說明 | 資料來源 |
| --- | --- | --- |
| 代碼 | 公司的內部名稱；新增時不可與現有公司重複 | 使用者輸入 |
| 顯示名稱 | 遊戲中看到的名稱，填的是目前語言的翻譯 | 使用者輸入 |
| 所有者類別、特色公司 | 公司的類別，以及是否為特色（歷史）公司 | 遊戲資料 |
| 圖示與背景 | 公司的圖片：選現有的，或導入自己的（見主程式規格 5.3.1.1） | 遊戲與模組的圖片、導入的圖片 |
| 經營產業 | 公司可以擁有的建築類型，以及之後可透過特許加入的建築 | 產業 |
| 名貴商品 | 公司可以生產的名貴商品 | 名貴商品 |
| 繁榮加成 | 公司繁榮時給的 buff / debuff 與數值 | buff / debuff |
| 總部位置 | 優先設立總部的州，按「選擇…」在地圖視窗點選（可標出已有公司的總部，見主程式規格 5.3.1.2） | 州、地圖 |
| 條件 | 顯示、可達成、建立條件，以及建築所在地區（見 3.3） | 條件清單 |
| AI | AI 建立條件、AI 權重、AI 建造目標（見 3.4） | 條件清單 |
| 進階 | 其他欄位的腳本，原樣寫入 | 使用者輸入 |

名貴商品的條件（`prestige_goods_trigger`）放在名貴商品區，以腳本書寫（原版只用來顯示提示）。

### 3.3 條件

用共用的條件清單編輯：

| 區塊 | 腳本欄位 | 可用的條件類型 |
| --- | --- | --- |
| 顯示條件 | `potential` | 國家範圍的條件（科技、建築、地區、整個地域、利益、國家、文化、DLC） |
| 可達成條件 | `attainable` | 同上；可勾選「在遊戲中隱藏」（`hidden_trigger`，原版常用） |
| 建立條件 | `possible` | 同上 |
| 建築所在地區 | `can_establish_in` | 地域是、地區已整合 |

快速範本：選地域（自動帶入所屬戰略區域）、科技、建築與等級，一次產生顯示、可達成、建立條件、AI 建立條件、AI 建造目標，並把地域加入總部；已有內容時先確認。

### 3.4 AI

- AI 建立條件（`ai_will_do`）三選一：與建立條件相同（預設）／自訂條件（條件清單）／AI 不會建立。
- AI 權重（`ai_weight`）填數字（寫成 `value = N`）；原本是公式的，改用腳本編輯。
- AI 建造目標（`ai_construction_targets`）是「建築＋等級＋地域（可留空）」的清單。

### 3.5 右欄：目前所有的公司

列出遊戲本體與已加載模組中的所有公司，需要有 filter。

- 點選一間公司，可以帶入編輯區修改，輸出後覆蓋原本的公司。
- 也可以把現有公司複製成範本，改成一間新公司。

〔初版做法〕

- 篩選條件：名稱搜尋、來源、產業、戰略區域（依總部所在地）、是否有名貴商品。
- 戰略區域篩選只列出有公司總部的區域，並顯示公司數量。
- 重複定義的公司（例如遊戲本體的公司被模組覆蓋）會顯示所有來源的標籤：生效的定義（最後載入的）正常顯示，被取代的較淡；篩選任一來源都找得到它，來源後的數量也照這樣計算。
- 重複定義的公司展開後有「版本」選擇，每個來源一個版本。詳情顯示所選版本的內容，「修改（覆蓋）」與「複製為新公司」都使用所選的版本，並提示這個版本與生效版本相同、差異只在條件／AI／其他腳本，或差異在顯示的欄位中。產業、戰略區域、名貴商品篩選只看生效的版本。

## 4. 輸出

〔初版做法〕

- 公司定義：`common/company_types/zzz_<模組>_companies.txt`
- 翻譯：`localization/<語言>/<模組>_companies_l_<語言>.yml`；覆蓋現有公司的名稱寫在 `localization/<語言>/replace/`
- 覆蓋現有公司：`REPLACE_OR_CREATE:company_xxx = { ... }`，寫出完整的定義。

## 5. 限制與待驗證

- 產生的模組還沒有在遊戲裡實際載入測試。
- 條件清單認不出的條件以腳本列保留（見主程式規格 5.3.2 與第 8 節）。
