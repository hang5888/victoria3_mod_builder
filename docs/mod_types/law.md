# 模組類型：法律

> 共用的部分（資料讀取、編輯頁框架、sidebar、選擇器、圖片導入、條件清單、輸出規則）見 [主程式規格](../mod_builder.md)。
> 遊戲檔案格式對照 1.15.1。

可以新增法律與法律組，也可以修改、覆蓋現有的法律。狀態：初版已實作（還沒有在遊戲裡實際載入測試）。

實作：前端 `frontend/js/law.js`，後端 `backend/laws.py`。原版 148 條法律都能讀進模型、原樣寫回並通過檢查（自動測試以外，另外用原版資料逐條確認過）。

## 1. 遊戲中的結構

一條法律由這幾部分組成：

| 部分 | 位置 | 內容 |
| --- | --- | --- |
| 法律 | `common/laws/` | 所屬法律組、圖示、進步程度、效果（修正）、解鎖條件、頒布條件、頒布／生效時執行的腳本、AI |
| 法律組 | `common/law_groups/` | 法律的分類（權力結構、經濟、人權），同一組裡一次只能實行一條 |
| 意識形態 | `common/ideologies/` | 每個意識形態對每條法律的態度（強烈支持、支持、中立、反對、強烈反對） |
| 利益集團 | `common/interest_groups/` | 每個利益集團一開始有哪些意識形態，因此支持或反對哪些法律 |
| 制度 | `common/institutions/` | 部分法律會建立制度（例如工作場所安全），可以投資提升等級 |
| 開局法律 | `common/history/countries/` | 各國開局時實行的法律（`activate_law = law_type:law_x`） |
| 翻譯 | `localization/` | 法律名稱 `law_x`、說明 `law_x_desc`；法律組 `lawgroup_x`、`lawgroup_x_desc` |
| 圖示 | `gfx/interface/icons/law_icons/` | 原版多為 302×302（69 張）或 256×256（60 張） |

範例（原版 `law_worker_protections`）：

```
law_worker_protections = {
    group = lawgroup_labor_rights
    icon = "gfx/interface/icons/law_icons/worker_protections.dds"
    progressiveness = 100
    unlocking_technologies = { human_rights }
    institution = institution_workplace_safety
    institution_modifier = { building_minimum_wage_mult = 0.1 }
    ai_enact_weight_modifier = { ... }   # 原版幾乎每條法律都是同一段「請願」寫法
}
```

意識形態裡的態度（`common/ideologies/00_ig_ideologies.txt`，節錄）：

```
ideology_paternalistic = {
    lawgroup_labor_rights = {
        law_no_workers_rights = neutral
        law_regulatory_bodies = disapprove
        law_worker_protections = strongly_disapprove
    }
}
```

### 1.1 原版統計

原版有 148 條法律、26 個法律組，分成三類：權力結構 10 組、經濟 8 組、人權 8 組。

各欄位有多少條法律使用：

| 欄位 | 數量 | 意思 |
| --- | --- | --- |
| `group`、`icon`、`progressiveness` | 148 | 所屬法律組、圖示、進步程度 |
| `ai_enact_weight_modifier` | 146 | AI 想頒布的程度（幾乎都是同一段「請願」寫法） |
| `modifier` | 129 | 實行時給國家的修正 |
| `unlocking_technologies` | 75 | 需要的科技 |
| `ai_will_do` | 63 | AI 是否會考慮這條法律（條件） |
| `on_enact` | 58 | 頒布過程中執行的腳本 |
| `disallowing_laws` | 50 | 實行這些法律時不能頒布 |
| `on_activate` | 48 | 法律生效時執行的腳本 |
| `can_impose`、`ai_impose_chance` | 47、38 | 宗主國能不能把這條法律強加給附庸、AI 強加的機率 |
| `is_visible` | 43 | 什麼國家看得到這條法律（條件） |
| `can_enact` | 32 | 頒布條件 |
| `institution`、`institution_modifier` | 25、21 | 建立的制度、制度的修正（依制度投資等級計算，待在遊戲確認） |
| `parent` | 22 | 「上層法律」：沿用它的意識形態態度，並被當成它的變體（見 1.2） |
| `unlocking_laws`、`requires_law_or` | 17、6 | 需要先實行某些法律（兩者的差別待查） |
| `on_deactivate` | 9 | 法律被取代時執行的腳本 |
| `tax_modifier_very_low` … `tax_modifier_very_high` | 7 | 稅收法律在五種稅率下的修正 |
| `acceptance_modifier` | 7 | 公民權法律對各接受度的修正 |

法律組的欄位：`law_group_category`（分類）、`ideological_opinion_impact`（國家間意識形態好感的權重）、`base_enactment_days`（頒布天數）、`enactment_approval_mult`、`affected_by_regime_change`、`change_allowed_trigger`、`linked_social_hierarchy`、`enable`。

### 1.2 新法律和其他內容的關係

這是做法律最需要注意的地方：

- **利益集團的態度寫在意識形態裡，不在法律裡。** 新法律如果沒有任何意識形態提到它，所有利益集團對它都是中立：不會有利益集團推動或反對，政治運動也不會支持它。
- **`parent` 可以解決大部分問題。** 原版註解寫「Inherits ideological stances from parent」：設了 `parent` 的法律沿用上層法律的意識形態態度。而且遊戲裡用 `has_law_or_variant` 檢查的地方（原版 3352 處，例如政體、政黨、日誌）會把它當成上層法律的變體。只用 `has_law` 檢查特定法律的地方（原版 1074 處）不會。
- **要讓意識形態對新法律有不同的態度**，就要修改意識形態檔。原版的意識形態有 183 個；用 `INJECT` 加進去時，同一個法律組會出現兩段，遊戲會不會合併要在遊戲裡確認。
- **新的法律組**完全沒有意識形態提到。你啟用的模組 3472248460 的做法是建立新的意識形態，再用腳本效果 `add_ideology` 加到利益集團上，相當複雜。
- **很多遊戲內容檢查特定法律**（例如 `law_monarchy` 被引用 379 次）。覆蓋原版法律時只改效果比較安全；改代碼或刪除會讓這些內容失效。

### 1.3 限定國家的法律

有些法律只給某些國家用，原版有三種寫法：

| 寫法 | 位置 | 原版例子 |
| --- | --- | --- |
| 法律組連到一個社會階層 | 法律組的 `linked_social_hierarchy`（社會階層在 `common/social_hierarchies/`） | 種姓支配權 → 英屬印度種姓制度（印度教且南亞文化的人口）；江戶等級制度 → 日本、琉球文化的人口 |
| 法律的顯示條件 | 法律的 `is_visible`（43 條） | 幕府 `c:JAP ?= this`；米勒特制限土耳其；官方民族性限俄國；武士階級、新選組、鎖國限日本文化 |
| 法律組的啟用條件 | 法律組的 `enable`（1 組） | 海軍模式：要有沿海地區 |

- 在受限的法律組裡新增的法律，自動受同樣的限制（限制寫在組上）。
- 複製有顯示條件的法律時，顯示條件也一起複製。

## 2. 資料

除了主程式已讀的資料（科技、修正、法律名稱等），另外讀取：

| 資料 | 用途 | 來源位置 |
| --- | --- | --- |
| 法律（全部欄位） | 右欄的現有法律清單、範本 | `common/laws/` |
| 法律組 | 法律組選項、分類 | `common/law_groups/` |
| 意識形態 | 顯示各利益集團對法律的態度 | `common/ideologies/` |
| 利益集團 | 利益集團的基本意識形態 | `common/interest_groups/` |
| 制度 | 制度選項 | `common/institutions/` |
| 社會階層 | 新法律組的社會階層選項（不含預設的那個） | `common/social_hierarchies/` |
| 圖片 | 法律圖示 | `gfx/interface/icons/law_icons/` 等（加上法律實際引用的路徑） |

和公司、工廠一樣，重複定義的法律記錄所有來源與各來源的版本。

## 3. 畫面

法律頁仿照遊戲裡的法律畫面，有兩種畫面（使用者回覆，見第 6 節）：

| 畫面 | Sidebar | 其他部分 |
| --- | --- | --- |
| 看板（開始畫面） | 模組內容（分類「法律組」「法律」） | 三欄看板佔滿中間和右邊 |
| 編輯畫面 | 同上 | 預覽欄＋編輯區；編輯區右上角 ✕ 回到看板 |

### 3.0 看板

- 和遊戲一樣分成三欄：權力結構、經濟、人權（法律組的 `law_group_category`）。每欄列出這一類的法律組卡片，卡片上有法律組的名稱和法律數量。
- 點法律組卡片：在卡片下方展開清單，列出這一組的所有法律（圖示＋名稱）。可以同時展開好幾組來比較，再點一次收合。
- 點清單中的一條法律：進入編輯畫面修改它（輸出時覆蓋原本的法律）。如果你的模組已經改過這條法律，就打開模組裡的版本。
- 清單最下面是「＋ 新增法律」：新法律直接屬於這一組，法律組欄位自動填好。
- 每一欄最下面是「＋ 新增法律組」（見 3.4）。
- 〔初版做法〕看板上方有搜尋（名稱或代碼）和來源篩選；符合搜尋的法律組自動展開，並標出符合的法律。
- 〔初版做法〕清單中被你的模組修改過的法律標「已修改」，新增的標「新增」；法律組卡片上也標出組裡有幾條被修改或新增。
- 〔初版做法〕清單中每條法律右邊有「複製」小按鈕：複製成同一組的新法律，`parent` 預設設成被複製的法律。
- 〔初版做法〕重複定義的法律在清單中顯示來源標籤；有多個來源時，打開後在編輯畫面上方選擇要以哪個版本為基礎（和公司相同的版本選擇）。
- 法律組的順序照遊戲檔案中的順序；模組新增的法律組排在同一欄的最後。
- 每組最先讀到的法律標「預設」（國家沒設定初始法律時用它，見 3.3）。
- 限定標示（使用者回覆要做，見 1.3）：
  - 法律組卡片：連到社會階層的標「限＜社會階層＞」（例如「限英屬印度種姓制度」），有啟用條件的標「有啟用條件」；滑鼠移上去顯示說明或條件腳本。
  - 法律：有顯示條件的標出摘要。〔初版做法〕條件清單讀得懂的「國家是」「主要文化」寫成「限日本」「限大和文化」，還有其他條件時加「（另有條件）」；讀不懂的寫「有顯示條件」；滑鼠移上去顯示完整的條件腳本。

### 3.1 預覽欄

- 名稱、圖示、法律組與分類、進步程度、解鎖科技。
- 效果摘要（修正）；有制度時顯示制度與制度修正。
- 各利益集團的態度：依每個利益集團的基本意識形態，列出支持、中立、反對（有 `parent` 時用上層法律的態度；沒有就全部中立）。
  - 〔初版做法〕預覽欄只顯示支持、中立、反對各有幾個利益集團；編輯區「利益集團的態度」列出每個利益集團和它各意識形態的態度。
  - 〔初版做法〕利益集團的態度是它開局各意識形態的加總：強烈支持 +2、支持 +1、中立 0、反對 −1、強烈反對 −2；大於 0 顯示支持，小於 0 顯示反對。遊戲中領袖和事件會改變意識形態，所以只是參考。
- 限定：法律組的限定與這條法律的顯示條件摘要（同看板）；沒有就寫「所有國家都能使用」。
- 同一組的其他法律與它們的進步程度，方便比較。
- 各語言名稱是否已填；問題提示。

### 3.2 編輯區

| 區塊 | 項目 | 寫成 |
| --- | --- | --- |
| 基本資訊 | 代碼（慣例 `law_` 開頭）、名稱、說明、法律組（鎖定，只顯示）、進步程度 | 定義的鍵、翻譯 `law_x`／`law_x_desc`、`group`、`progressiveness` |
| 圖片 | 圖示；可選現有或導入 | `icon` |
| 利益集團的態度 | 上層法律：從同一組的法律中選（不含自己），沿用它的態度；可以不選（全部中立） | `parent` |
| 解鎖與限制 | 解鎖科技、需要的法律、不相容的法律、顯示條件、頒布條件 | `unlocking_technologies`、`unlocking_laws`／`requires_law_or`、`disallowing_laws`、`is_visible`、`can_enact` |
| 效果 | 國家修正（和公司的繁榮修正同樣的修正清單）；制度與制度修正 | `modifier`、`institution`、`institution_modifier` |
| 特殊效果 | 只在對應的法律組出現：稅收的五種稅率修正、公民權的接受度修正 | `tax_modifier_*`、`acceptance_modifier` |
| 腳本 | 頒布中、生效、被取代時執行的腳本：腳本文字框，附原版常見寫法當範例 | `on_enact`、`on_activate`、`on_deactivate` |
| AI | AI 想頒布的程度（預設原版的請願寫法）、AI 是否考慮、強加給附庸 | `ai_enact_weight_modifier`、`ai_will_do`、`can_impose`、`ai_impose_chance` |
| 其他腳本 | 工具不認得的欄位 | 原樣 |

- 法律組在看板上新增法律時決定，新增、複製、修改時都不能改（使用者回覆，見第 6 節第 8 題）。
- 顯示條件、頒布條件用條件清單（國家範圍）。
- 「需要的法律」「不相容的法律」用選擇器，選項是所有法律，依法律組分組顯示。
- 〔初版做法〕上層法律的選項只列同一組裡本身沒有上層法律的法律（原版的上層法律都是這樣）。新增的法律預設沒有上層法律，預覽欄提示「所有利益集團都中立」。

### 3.3 開局法律（不在法律頁）

法律頁不設定開局法律（使用者回覆，見第 6 節第 4 題）：「所有國家開局實行」「設為這組的預設法律」「各國自己的開局法律」都留給之後的「國家開局」類型。以下是查到、之後會用到的資料：

- 遊戲裡沒有「預設法律」這個欄位。國家的開局歷史沒有設定某一組的法律時，用這一組最先讀到的法律（原版英國沒設定的 4 組都是這樣，例如勞動者權益用「無勞動者權利」）。看板上標「預設」的就是這條。
- 原版各國的開局法律寫在 `common/history/countries/` 的 `activate_law`（450 個檔案，全部直接寫在 `c:TAG` 底下），大多經由 `effect_starting_politics_traditional` 等腳本效果；腳本效果裡只用到「是否為部落國家」（國家定義的 `country_type`）與「國教是否為伊斯蘭」兩種條件，所以可以算出每個國家實際的開局法律。
- `common/history/global/` 的檔案在所有開局歷史的最後執行（原版檔案的註解），可以用 `every_country = { activate_law = ... }` 蓋過各國的設定；你啟用的大型模組 2932134122 就是這樣寫。
- 要讓一條新法律成為預設，可以把它寫在比原版更早讀取的法律檔（例如 `00_00_` 開頭）；讀取順序要在遊戲裡確認。
- 開局歷史的 `activate_law` 不檢查顯示條件、頒布條件和解鎖科技：限定的法律（見 1.3）也會被設上。

### 3.4 新增法律組（使用者回覆，見第 6 節第 8 題）

- 入口：看板每一欄最下面的「＋ 新增法律組」；新法律組的分類就是那一欄，之後不能改。只能新增，現有的法律組不修改。
- 看板上，模組新增的法律組排在同一欄的最後，標「新增」；展開後有「編輯法律組」按鈕。
- Sidebar 多一個分類「法律組」，放模組新增的法律組。
- 編輯畫面（預覽欄＋編輯區，和法律相同的版面）：

| 區塊 | 項目 | 寫成 |
| --- | --- | --- |
| 基本資訊 | 代碼（慣例 `lawgroup_` 開頭）、名稱、說明、分類（鎖定） | 定義的鍵、翻譯 `lawgroup_x`／`lawgroup_x_desc`、`law_group_category` |
| 設定 | 意識形態好感權重（預設 1）、頒布天數（空白用遊戲預設）、認可度影響倍率（空白為 1）、政權更迭時改變、社會階層 | `ideological_opinion_impact`、`base_enactment_days`、`enactment_approval_mult`、`affected_by_regime_change`、`linked_social_hierarchy` |
| 條件 | 啟用條件、修改條件（條件清單，國家範圍） | `enable`、`change_allowed_trigger` |
| 這組的法律 | 模組在這組的法律（點開編輯）；保存法律組後才能「＋ 新增法律」 | — |
| 其他腳本 | 工具不認得的欄位 | 原樣 |

- 預設法律：沒有國家的開局歷史會設定新法律組，所以所有國家開局都實行這組最先讀到的法律，也就是第一條建立的法律（使用者選擇）。法律照建立的順序寫出，第一條標「預設」。
- 利益集團的態度：新法律組的法律沒有上層法律可選，所有利益集團都中立（使用者選擇）；編輯區和預覽欄都會說明。
- 〔初版做法〕改了法律組的代碼並保存時，模組中這組的法律跟著改到新代碼。
- 〔初版做法〕刪除法律組時，模組中這組的法律一起刪除（刪除前的確認視窗會寫出條數）。
- 〔初版做法〕新法律組還沒有法律時，預覽欄提示至少要有一條。

## 4. 輸出

- 法律組：`common/law_groups/zzz_<模組>_law_groups.txt`。
- 法律：`common/laws/zzz_<模組>_laws.txt`，照建立的順序寫出（新法律組的第一條就是預設法律）。
- 翻譯：法律與法律組的名稱與說明，只有填寫的語言；覆蓋的名稱寫在 `replace/`。
- 覆蓋現有法律：`REPLACE_OR_CREATE:<代碼> = { ... }`，寫出完整定義。
- 導入的圖片照主程式規格打包。〔初版做法〕法律圖示的導入尺寸用 302×302（原版最多的尺寸），等比縮放放進正方形。
- 不修改意識形態檔（待確認 2 回覆 A）。

## 5. 初版不做（建議）

- 修改現有的法律組（第 8 題回覆：只能新增）。
- 逐一設定各意識形態對法律的態度（待確認 2 回覆「先做 A 之後再調整」）。
- 開局法律：所有國家、預設法律、各國自己的開局法律（之後的「國家開局」類型，見 3.3）。
- 新增制度（只能選原版的 6 個制度）。
- 修正案（`common/amendments/`）。
- 政體、政黨、政治運動等依法律判斷的內容。
