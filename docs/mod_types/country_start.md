# 模組類型：國家開局

> 共用的部分（資料讀取、編輯頁框架、sidebar、選擇器、圖片導入、條件清單、輸出規則）見 [主程式規格](../mod_builder.md)。
> 遊戲檔案格式對照 1.15.1。

設定國家開局時的狀態：可以修改現有國家，也可以新增國家。分四個階段做（使用者回覆，見第 7 節第 8 題）。狀態：四個階段都已實作：第 1 階段（世界畫面、國家、政治、科技、其他腳本）、第 2 階段（領土、人口、建築）、第 3 階段（外交、條約、人物）、第 4 階段（新增國家、國旗），還沒有在遊戲裡實際載入測試。各部分屬於哪個階段見 3.2 的表。

實作：前端 `frontend/js/country.js`、`frontend/js/territory.js`（領土、人口、建築分頁；地圖在 `frontend/js/map.js` 的 `CountryMap`）、`frontend/js/relations.js`（外交、人物分頁）、`frontend/js/flag.js`（新國家的國旗：畫國旗與編輯），後端 `backend/countries.py`、`backend/territory.py`、`backend/diplomacy.py`（外交、條約）、`backend/characters.py`（人物）、`backend/flags.py`（國旗）（讀取在 `backend/gamedata.py`）。

範圍（使用者回覆）：

- 對象：修改現有國家＋新增國家。
- 初版包含：法律與政治；科技、財富與識字率；領土；外交；人口；建築；人物。
- 選國家：地圖＋清單。
- 法律頁移過來的「所有國家開局實行」放在這裡；預設法律不另外設定，照遊戲機制用每組最先讀到的法律（見第 7 節第 6 題、[law.md](law.md) 1.4）。

## 1. 遊戲中的結構

國家的開局分散在很多檔案：

| 部分 | 位置 | 內容 | 原版規模 |
| --- | --- | --- | --- |
| 國家定義 | `common/country_definitions/` | 顏色、等級、類型、主要文化、首都、宗教、社會階層 | 835 個（含 100 個可成立的國家） |
| 國名 | `localization/` | `GBR`（名稱）、`GBR_ADJ`（形容詞）、`GBR_DEF`（正式名稱） | |
| 國旗 | `common/flag_definitions/`、`common/coat_of_arms/coat_of_arms/` | 國旗定義（依條件選用哪個紋章）與紋章圖案 | |
| 國家歷史 | `common/history/countries/` | 法律、科技、執政利益集團、稅率、關稅、制度投資、被課稅商品等 | 450 個檔案，一國一檔 |
| 執政黨 | `common/history/governments/` | 執政黨與政黨聲勢 | 5 國 |
| 財富與識字率 | `common/history/population/` | 人口財富、識字率等級 | 373 個檔案，一國一檔 |
| 領土 | `common/history/states/00_states.txt` | 每個地域由哪些國家擁有哪些省份、家園、宣稱 | 1 個檔案 |
| 人口 | `common/history/pops/` | 每個地區的人口（文化、宗教、職業、人數） | 17 個檔案，依地理區分 |
| 建築 | `common/history/buildings/` | 每個地區的建築（等級、擁有者、生產方式） | 16 個檔案，依地理區分 |
| 人物 | `common/history/characters/`、`common/character_templates/` | 開局的人物（統治者、利益集團領袖、將軍） | 268 個檔案；人物範本 2071 個 |
| 外交 | `common/history/diplomacy/` | 附庸、關係值、宿敵、停戰、禁運、人情 | 6 個檔案 |
| 條約 | `common/history/treaties/00_historical_treaties.txt` | 防禦同盟、保證獨立、軍事通行、貿易特權、商品轉移、條約港等 | 1 個檔案，46 個條約 |
| 全局 | `common/history/global/` | 所有開局歷史之後才執行 | 1 個檔案 |

`common/history/` 還有這些資料夾，初版不處理（見第 6 節）：城市中心的生產方式（`production_methods`）、AI（`ai`）、文化（`cultures`）、徵兵中心（`conscription`）、軍隊編制與部署（`military_formations`、`military_deployments`）、勢力集團（`power_blocs`）、貿易路線（`trade`）、政治運動（`political_movements`）、遊說團體（`lobbies`）、外交博弈（`diplomatic_plays`）、組閣（`government_setup`，原版只有註解）。

### 1.1 國家定義

```
GBR = {
    color = hsv{ 0.99 0.7 0.9 }
    country_type = recognized
    tier = empire
    cultures = { british scottish }
    capital = STATE_HOME_COUNTIES
}
```

- 欄位使用次數：`cultures`、`tier`、`country_type`、`color` 735；`capital` 734；`dynamic_country_definition` 100；`is_named_from_capital` 91；`regnal_numbers` 63；`religion` 57；`social_hierarchy` 43；部隊顏色 7。
- 國家類型：`recognized`（受承認）、`unrecognized`（未受承認）、`decentralized`（部落）、`colonial`（殖民地）、`company`（公司）。
- 等級：`city_state`、`principality`、`grand_principality`、`kingdom`、`empire`、`hegemony`。
- 國家定義是資料庫，可以用 `REPLACE_OR_CREATE` 覆蓋。

### 1.2 國家歷史（`common/history/countries/`）

```
COUNTRIES = {
    c:GBR ?= {
        effect_starting_technology_tier_1_tech = yes
        add_technology_researched = labor_movement
        set_tax_level = medium
        add_taxed_goods = g:liquor
        set_import_tariff_level = { goods = g:grain level = high_tariffs }
        ig:ig_intelligentsia ?= { add_ruling_interest_group = yes }
        activate_law = law_type:law_monarchy
        set_institution_investment_level = { institution = institution_colonial_affairs level = 2 }
    }
}
```

原版各語句的使用次數：

| 語句 | 次數 | 意思 |
| --- | --- | --- |
| `activate_law` | 1453 | 開局法律 |
| `effect_starting_politics_traditional` 等 5 種 | 413 | 一組開局法律（傳統、保守、反動、自由、土邦） |
| `ig:<利益集團> = { add_ruling_interest_group = yes }` | 190 | 執政利益集團（同一段也有改名、加意識形態） |
| `effect_starting_technology_tier_1_tech` … `tier_7` | 450 | 科技等級（1 最先進，7 最落後） |
| `add_technology_researched` | 137 | 額外的科技 |
| `set_import_tariff_level`、`set_export_tariff_level` | 60、8 | 關稅 |
| `set_institution_investment_level` | 60 | 制度投資等級 |
| `add_taxed_goods` | 52 | 被課消費稅的商品 |
| `set_tax_level` | 27 | 稅率 |
| `set_next_election_date` | 17 | 下次選舉日期 |
| 其他（`add_journal_entry`、`set_variable`、`add_modifier`、`add_company`、主要文化…） | 約 150 | 原樣保留成腳本 |

開局法律的計算方式（之前為法律頁查到的）：大多國家用 `effect_starting_politics_*`，裡面只有「是否為部落國家」「國教是否為伊斯蘭」兩種條件；沒設定的法律組用該組最先讀到的法律。

### 1.3 財富與識字率（`common/history/population/`）

```
POPULATION = {
    c:GBR ?= {
        effect_starting_pop_wealth_very_high = yes
        effect_starting_pop_literacy_high = yes
    }
}
```

財富 4 級（low、medium、high、very_high）、識字率 6 級（very_low、low、baseline、middling、high、very_high），都定義在 `common/scripted_effects/`。

### 1.4 領土（`common/history/states/00_states.txt`）

```
STATES = {
    s:STATE_PROVENCE = {
        create_state = { country = c:SAR owned_provinces = { x5080E0 } }
        create_state = { country = c:FRA owned_provinces = { ... } state_type = unincorporated }
        add_homeland = cu:french
        add_claim = c:SAR
    }
}
```

- 一個地域（state region）可以分給好幾個國家，每個國家擁有其中幾個省份（地區 state）。省份的代碼就是它在 `provinces.png` 上的顏色，工具的地圖已經用這個顏色把省份對應到地域。目前地圖只分到地域，而且用一半的解析度處理，領土分頁要點選省份時，小省份可能點不到，實作時要處理。
- `create_state` 1156 次（地域 676 個）；`state_type = unincorporated`（未併入）175 次；`add_homeland` 1340 次；`add_claim` 107 次。
- 一個國家要擁有至少一個地區，開局才會存在。

### 1.5 人口（`common/history/pops/`）

```
POPS = {
    s:STATE_HOME_COUNTIES = {
        region_state:GBR = {
            create_pop = { culture = british size = 2657596 }
            create_pop = { culture = british religion = catholic size = 100000 }
        }
    }
}
```

- `create_pop` 4483 次；欄位：`culture`、`size`（必有）、`religion`（969）、`pop_type`（693）。沒寫宗教用文化的宗教；沒寫職業由遊戲分配。
- 人口記在「地域裡某國的地區」（`region_state:TAG`）底下。

### 1.6 建築（`common/history/buildings/`）

```
BUILDINGS = {
    s:STATE_SVEALAND = {
        region_state:SWE = {
            create_building = {
                building = "building_government_administration"
                add_ownership = { country = { country = "c:SWE" levels = 4 } }
                reserves = 1
                activate_production_methods = { "pm_professional_bureaucrats" "pm_horizontal_drawer_cabinets" }
            }
        }
    }
}
```

- `create_building` 3162 次。擁有者 `add_ownership` 有三種：國家（961）、另一棟建築（2527，例如莊園、金融區）、公司（23）。少數用 `level` 直接給等級。
- 擁有者是建築時，寫的是那棟建築的種類、國家和地域：`building = { type = "building_manor_house" country = "c:BIC" levels = 5 region = "STATE_BIHAR" }`。原版裡，擁有者建築和被持有的建築在同一個地區的有 2223 筆，在同一國的其他地區的有 194 筆（例如首都的金融區），屬於別國的有 110 筆。

### 1.7 人物

- 開局人物幾乎都是 `create_character = { template = gbr_queen_victoria_template }`（858／859 次），內容寫在人物範本。
- 人物範本欄位：名、姓、文化、宗教、利益集團、意識形態、特質、出生日期、性別、角色（統治者 `ruler`、繼承人 `heir`、利益集團領袖 `ig_leader`、將軍 `is_general`／指揮官等級）、外觀 `dna`（641 個有）等。
- 人物的檔案大多一國一檔，但日本的檔案有 2 國、秘魯的有 3 國；取代時同一檔的其他國家原樣保留。

### 1.8 外交（`common/history/diplomacy/`）

- `create_diplomatic_pact = { country = c:X type = ... }`：puppet 64、protectorate 16、colony 15、rivalry 10、vassal 9、tributary 6、personal_union 6、crown_land 5、chartered_company 3、dominion、embargo 等。
- `set_relations = { country = c:SPA value = -30 }`（247 次）、`add_liberty_desire`（20）、停戰 `create_bidirectional_truce`（5）、人情 `set_owes_obligation_to`（4）。

#### 1.8.1 條約（`common/history/treaties/`）

```
TREATIES = {
    create_treaty = {
        name = treaty_name_holy_alliance      # 條約名稱（翻譯鍵），可以沒有
        first_country = c:RUS
        second_country = c:AUS
        is_draft = no
        entered_into_force_on = 1815.10.26
        binding_period = { years = 35 }
        articles_to_create = {
            { article = defensive_pact }
            { article = goods_transfer source_country = c:POR target_country = c:GBR
              inputs = { { goods = g:wine } { quantity = 20 } } }
        }
    }
}
```

- 原版 46 個條約。條款次數：貿易特權 14、商品轉移 14、保證獨立 11、過境權 10、軍事援助 9、防禦同盟 9、軍事通行 7、金錢轉移 5、條約港 3、支持獨立 3、法律承諾 3、外國投資權 3、勢力集團大使館 2。
- 條款定義在 `common/treaty_articles/`（34 種）：雙向（`mutual`，例如防禦同盟）不用寫給予方和接受方；單向（`directed`）要寫 `source_country`、`target_country`。有些條款要填參數（`required_inputs`）：商品、數量、法律、地區、公司、國家、戰略區域、建築種類。
- 有 3 組條約包在「有沒有某個 DLC」的 `if`／`else` 裡，兩邊各寫一份。

### 1.9 模組怎麼改開局（重要）

- 開局歷史不是資料庫，沒有代碼可以 `REPLACE`；它是依序執行的效果腳本。後面的檔案只能「再加上」效果，沒辦法刪掉前面建立的人口、建築或地區。
- 所以模組改開局的通用做法是**放一個同名檔案，整個取代原本的檔案**。工作坊的模組也是這樣：2932134122（Better Politics Mod）取代美國、巴西等國家歷史；3371693463（States Merging）取代 `00_states.txt` 和西歐、南歐、東歐的人口與建築檔。
- 地域、人口、建築、條約的檔案是好幾個國家共用一個（`00_states.txt` 是全世界一個檔），取代時必須寫出整個檔案。

## 2. 做法（使用者回覆，見第 7 節第 1 題）

**複製目前生效的那個檔案，只換掉這個國家相關的段落**，其他內容（包括註解）原樣保留，寫在同樣的路徑取代原檔：

- 國家歷史、財富與識字率、人物：一國一檔，換掉該國的檔案。
- 領土、人口、建築、外交、條約：換掉含有該國段落的檔案，只改有關的 `s:STATE`、`c:TAG` 段落或 `create_treaty`。
- 「目前生效的檔案」是工具讀到的版本：如果已啟用的模組取代過它，就以該模組的版本為基礎，所以會保留它的修改。遊戲中你的模組要排在它後面。
- 〔初版做法〕專案檔只記你改了什麼（例如「英國的治理原則改成總統共和制」「這幾個省份給法國」），不存整份檔案；每次保存都從當時讀到的檔案重新套用這些修改再寫出。所以換了啟用的模組或遊戲改版後，重新保存就會以新的檔案為基礎。
- 〔初版做法〕政治分頁改了某條開局法律時，原本的 `effect_starting_politics_*` 保留，在它後面加一行 `activate_law`（後執行的會蓋過前面的）；如果國家檔裡這一組已經有 `activate_law`，就換掉那一行，不再多加。科技等級直接換掉 `effect_starting_technology_tier_*` 那一行。
- 新國家另外寫新檔案（國家定義、國家歷史、人物等）；它的領土、人口、建築一樣寫進上面那些被取代的檔案。
- 以前的修改套用不上時（例如換了啟用的模組，地域裡已經沒有那個省份），跳過那一項，在預覽欄提示。

### 2.1 領土轉移（使用者回覆，見第 7 節第 3、12、13 題）

- 整個地區轉給新國家時，人口和建築一起轉過去，建築的擁有者這樣改：
  - 原國家持有的部分改成新國家持有：國家本身持有的（`country = c:原國家`）、同一個地區的建築持有的（例如當地的莊園），以及原國家其他地區的建築持有的（例如首都的金融區，使用者選擇），都改成新國家。
  - 這個地區的建築在別的地區持有的部分（例如當地的莊園持有其他地區的農場），擁有者的國家改成新國家。
  - 其他國家持有的部分不變。
- 只轉移部分省份時，人口依省份數比例分給兩邊，建築留在原主人，擁有者不變。
- 〔初版做法〕新主人在這個地域本來就有地區時，轉過去的部分併進它的地區：人口文化、宗教、職業都相同的就把人數加總，同種類的建築把等級加總。
- 一個國家的地區全部給出去時，它開局就不存在（使用者選擇：允許）：
  - 預覽欄和世界畫面標出「開局不存在」。
  - 寫出時，刪掉外交裡提到它的段落（附庸、關係值、宿敵、停戰、禁運、人情）和有它的條約；它在別國持有的建築改成該地區的國家持有。
  - 它的國家歷史、人物等用 `c:X ?=` 寫的段落，遊戲會自動略過，原樣保留。

### 2.2 讀取（第 1 階段）

- 國家定義、國家歷史、財富與識字率、執政黨照第 1 節讀取；國家歷史的語句照 1.2 的表分類，工具不認得的放進「其他腳本」。
- 〔初版做法〕統計（地區、人口、建築、人物）從領土、人口、建築、人物的開局歷史算出來。
- 〔初版做法〕`effect_starting_politics_*` 的條件換算成「國家類型」「國教」兩種，編輯時依改過的類型、國教重新計算；國教沒設定時用第一個文化的宗教；DLC 條件當作都有。
- 〔初版做法〕政黨名稱用政黨定義裡最後一個名稱（沒有特殊條件時用的那個）。
- `dynamic_country_definition` 的 100 個佔位國家不列出。

### 2.3 專案檔記什麼

每個國家只記改了什麼（`country_starts`）：

- 第 1 階段：改過的定義欄位、各組的開局法律、利益集團名稱，其他部分整個記下來或記 `null`（照遊戲）。
- 第 2 階段：

| 欄位 | 內容 |
| --- | --- |
| `gains` | 這個國家取得的省份（不管原本是誰的） |
| `releases` | 這個國家原本的省份中，放棄成無主的 |
| `state_types` | 地區改成已併入／未併入 |
| `homelands` | 各地域加入、移除的家園文化 |
| `claims` | 加入、移除的宣稱 |
| `pops`、`buildings` | 改過的地區的整份人口、建築清單 |

- 第 3 階段：

| 欄位 | 內容 |
| --- | --- |
| `diplomacy` | `null`（照遊戲），或這個國家參與的所有外交語句（整份清單）：`{kind, first, second, type, value}`，見 3.2.3 |
| `treaties_added` | 新增的條約：`{names, first, second, date, years, articles}`，`first` 是這個國家 |
| `treaties_removed` | 要刪除的遊戲條約（用「兩國＋名稱＋生效日期」認出來） |
| `characters` | `null`，或整份人物清單：`{template, extra, new}`，見 3.2.4 |

- 〔初版做法〕一個省份只會被一個國家取得：保存某國時，它取得的省份會從其他國家的 `gains` 移除（其他國家因此沒有任何修改時，就從模組移除）。取回自己原本的省份時，不必記在 `gains`。
- 〔初版做法〕人口、建築的清單是「這個地區最後的樣子」：領土轉移先算，再套用你改過的清單。之後這個地區又換主人時，用遊戲原本的人口、建築重新計算，你改過的清單不再套用。

### 2.4 領土的計算（伺服器端，第 2 階段）

- 誰擁有哪些省份、人口和建築怎麼移動都在後端計算（`territory.World`），頁面改了領土就請伺服器重新計算（`/api/country_start/resolve`），地圖、地區清單、人口、建築和預覽欄的統計都用計算結果。
- 整個地區換主人：人口、建築一起轉移，持有者照 2.1 改寫；原本由這個地區的建築持有的其他地區建築（例如倫敦的金融區持有世界各地的建築），持有者跟著改成新國家。〔初版做法〕只有持有者變動的建築，只重寫那幾棟，同一地區的其他建築和註解原樣保留。
- 只轉移部分省份：人口依省份數分配（給無主省份的那份消失），餘數給原主人；建築留在原主人。〔初版做法〕原主人一個省份都沒剩、而分給好幾個國家時，建築給分到最多省份的國家。
- 〔初版做法〕新主人在這個地域本來就有地區時併在一起：文化、宗教、職業都相同的人口把人數加總；同種類的建築把等級和各持有者的等級加總。
- 〔初版做法〕新的地區（新主人原本在這個地域沒有地區）的已併入／未併入，跟著大部分省份原本所屬的地區。
- 國家失去所有土地時：外交（`common/history/diplomacy/`）裡以它為對象的語句、有它的條約（`common/history/treaties/`）都刪除；它在別國持有的建築改成該地區的國家持有。它自己用 `c:X ?=` 寫的段落遊戲會略過，原樣保留。

#### 3.2.1 國家、政治（第 1 階段）

- 政治分頁的開局法律看板：每張卡片顯示開局法律與來源標籤：歷史中設定、開局設定腳本（滑鼠移上去顯示腳本名稱）、預設、所有國家、你的修改。點開選一條法律；選回不含你的修改時的法律，就等於取消修改。限定國家的法律標出限定（同法律頁），選了的話預覽欄提示。
- 〔初版做法〕執政利益集團和改名放在同一張表：每個利益集團一列，勾選執政，名稱欄填這個國家的名稱。原版 450 個國家中只有 156 個設定執政利益集團，沒設定的由遊戲決定，預覽欄寫「不設定：由遊戲決定」。
- 首都（使用者回覆：用地圖選）：國家分頁的「首都」卡片按「在地圖上選…」開地圖視窗（見主程式規格 5.3.1.2），這個國家的土地是它的顏色，其他國家變暗，首都是金色；點地圖上的地區再按「完成」就設為首都。〔初版做法〕地圖一開始放大到首都附近的本國土地（不含遠方的殖民地）；視窗的清單沒有搜尋時列出本國的地區。首都不是開局擁有的地區時標出來。
- 選舉（使用者回覆：沒有選舉時不顯示執政黨與下次選舉日期）：遊戲沒有「有沒有選舉」的欄位，選舉是因為法律給了投票權。〔初版做法〕開局法律中有任何一條的修正含 `voting_power`（原版是土地投票、財產投票、人口普查投票、普選、一黨制、勞工選舉權）就算有選舉；沒有的話這張卡片只寫說明。改了開局法律會立刻重新判斷；沒有選舉卻還設定了執政黨或選舉日期時，提示並可以還原。
- 〔初版做法〕每個改過的欄位旁有「還原」，回到遊戲原本的值；改回和遊戲相同的值也自動當作沒改。全部還原後保存，模組裡就不再有這個國家。

#### 3.2.2 領土、人口、建築（第 2 階段）

轉移的規則照 2.1。

- 領土分頁：地圖顯示這個國家的土地（其他國家變暗，宣稱有斜線，首都金色）。點地圖有三種模式：省份（取得或放棄一個省份）、整個地域（取得整個地域，已經全有就全部放棄）、宣稱（加入或取消宣稱）。下面列出這個國家的每個地區：省份數、新取得或取得幾個省份的標示、未併入、家園（可加入、移除）、放棄整個地區；以及失去的地區。另有宣稱清單，按「選擇…」開地圖視窗（同首都的地圖，宣稱有斜線）。
- 人口分頁：依地區列出人口（文化、宗教、職業、人數），可以新增、刪除、改內容；隨領土變動的地區標「隨領土變動」，改過的標「已修改」，可以還原。〔初版做法〕地區預設收起來，點開才顯示內容。
- 建築分頁：依地區列出建築，每棟有等級、儲備、持有者（國家／建築／公司，各自的國家、種類、所在地域（用地圖視窗選）、等級）、每個生產方式組選一個生產方式；可以新增、刪除建築與持有者。

#### 3.2.3 外交與條約（外交分頁，第 3 階段）

外交分頁有兩張卡片：外交關係、條約。

- 外交關係列出外交檔（`common/history/diplomacy/`）裡這個國家參與的語句，不論寫在哪一國的段落（例如英國段落裡的「東印度公司是特許公司」也出現在東印度公司的頁面）：
  - 附庸與協定（`create_diplomatic_pact`）：對方國家、協定種類、⇄ 交換兩方。協定種類是 `common/diplomatic_actions/` 裡有 `pact` 的外交行動（原版 30 種），其中給附庸類型的就是附庸關係（傀儡、殖民地、共主邦聯…），其他如宿敵、禁運。語句寫在第一方（宗主、發起方）的段落。
  - 關係值（`set_relations`，-100 到 100）、停戰（`create_bidirectional_truce`，月數）、人情（`set_owes_obligation_to`，誰欠誰）、自主傾向（`add_liberty_desire`，只有這個國家自己，留空就不設定）。
  - 〔初版做法〕改了任何一項後，這個國家的外交就記成整份清單：寫出時，遊戲檔裡這個國家參與的所有語句（兩邊段落都算）換成清單上的；和原本一樣的語句留在原位不動。工具不認得的語句（`every_subject_or_below`、`if` 裡的、格式不同的）原樣保留，也不列出。
  - 〔初版做法〕新語句寫在第一方在「同種語句最多的那個檔案」裡的段落（例如傀儡寫進 `00_subject_relationships.txt`、宿敵寫進 `00_rivalries.txt`）；沒有檔案用過這種協定時，寫進協定最多的檔案；那個檔案沒有第一方的段落就在檔案最後加一段；外交檔裡完全沒有這類語句時才寫在新檔 `common/history/diplomacy/zzz_<模組>_diplomacy.txt`。
  - 〔初版做法〕兩個國家的開局都改了它們之間的外交時，後保存的為準：保存時，其他國家清單裡和這個國家有關的語句換成這個國家清單上的。
  - 頁面上「照遊戲」的清單已經套用其他國家開局的修改。對方開局不存在（見 2.1）時標出來，寫出時刪掉。
- 條約：列出這個國家參與的條約：你新增的（可以編輯）、其他國家的開局新增、和這個國家有關的（標出，在那個國家的頁面改），以及遊戲的條約（條款、方向、參數、生效日期、約束期限）。
  - 新增條約：選另一個國家、名稱（可以不填，寫成新的翻譯鍵 `<模組>_treaty_<代碼>_<n>`）、生效日期、約束期限（年）、條款。條款從 `common/treaty_articles/` 選（原版 34 種，要填艦船或文字的 2 種不列出）；單向的條款選方向（哪一方給、哪一方收）；要填參數的條款用選擇器選商品、法律、地區（加上是哪一方的地區）、戰略區域、公司、建築、國家，數量用數字欄位。
  - 刪除條約：遊戲的條約按「刪除」，再按「保留」取消。〔初版做法〕包在 DLC 條件（`if`／`else`）裡的條約兩份算同一個，刪除時兩份一起刪，整個條件只剩 `limit` 時連條件一起刪。新增的條約不加 DLC 條件。
  - 〔初版做法〕初版只能新增、刪除，不能修改現有條約的內容；要改就刪掉再新增。
  - 〔初版做法〕新增的條約都寫在新檔 `common/history/treaties/zzz_<模組>_treaties.txt`，原本的條約檔只有刪除條約時才取代。
  - 〔初版做法〕工具只檢查條款的格式（方向、參數齊全、參數存在）；條款本身的條件（例如條約港的地區要是給予方的、需要某個科技）不檢查，要在遊戲裡確認。

#### 3.2.4 人物（第 3 階段）

- 列出這個國家開局的人物（人物歷史裡 `c:TAG ?=` 段落第一層的 `create_character`）：人物範本的名字、角色、文化、利益集團、意識形態、出生日期；`create_character` 裡除了 `template` 以外的語句（例如 `on_created`）可以展開當腳本改。
- 「選擇人物範本…」從遊戲的人物範本（原版 2070 個，不含 `default`）多選，這個國家的範本排前面；在選擇視窗取消勾選就移除。
- 「新增人物」：名、姓（目前的語言；任何一種語言有名字就可以）、角色（統治者、繼承人、利益集團領袖、政治家、將軍、海軍將領、鼓動者）、指揮官等級（將軍、海軍將領）、出生日期（留空：隨機年齡）、文化（預設這個國家的第一個主要文化）、宗教、利益集團、意識形態（`character_ideology = yes` 的意識形態）、家鄉地區、性別、特質。
- 〔初版做法〕新的人物寫成人物範本 `<模組>_<代碼>_character_<n>`（`n` 是清單上第幾個新人物），放在 `common/character_templates/zzz_<模組>_characters.txt`，名字是新的翻譯鍵 `<範本>_first`、`<範本>_last`；加上 `historical = yes`，外觀（DNA）由遊戲隨機。
- 〔初版做法〕改了任何一項後，人物記成整份清單：寫出時，這個國家段落第一層的 `create_character` 換成清單（寫在第一個人物的位置），條件（`if`、`random_list`）裡的人物和其他語句原樣保留，頁面上顯示保留了幾句。
- 不只一個統治者時提示。

### 3.3 新國家（第 4 階段）

- 國家清單最上面的「＋ 新增國家」開一個視窗：先填代碼，再二選一（使用者回覆，見第 7 節第 5 題）：
  - 從現有國家複製：複製國家定義（類型、等級、文化、宗教、社會階層）、政治（法律、執政利益集團、稅率、關稅、制度、被課稅商品）、科技、財富與識字率。領土、人口、建築、人物、外交不複製，因為那些屬於原本的國家。
  - 從空白開始：類型「受承認」、等級「公國」，其他照遊戲機制（法律用每組的預設）；文化、首都要自己選。
- 〔初版做法〕代碼：三個字元，大寫字母開頭，其餘是大寫字母或數字（原版都是這樣）；不能和遊戲或模組裡的國家重複。代碼是國家的身分，之後不能改（要改就刪掉重做）。
- 〔初版做法〕複製時，複製的是原本國家在你的模組裡的樣子（包括你改過的部分）：開局法律換算成每一組明確的法律（開局設定腳本依國家類型、國教算出來的也一樣），不含「所有國家」的設定（那會套用到所有國家）；顏色另外隨機給一個，首都留空（土地不複製）。
- 新國家在國家清單排在最前面，標「新增」；還沒有土地時也會列出（不受「只列開局存在的」影響），預覽欄提示要在領土分頁給它省份。
- 新國家至少要有一個地區（在領土分頁給它省份），開局才會存在。〔初版做法〕還沒有土地、或已經刪掉的新國家，其他國家外交和條約裡提到它的部分不寫出（和失去所有土地的國家一樣）。
- 國家分頁多兩張卡片：代碼、國旗。國家定義的欄位都是新國家自己的，沒有「還原」。國名、形容詞、正式名稱寫成新的翻譯鍵（不放 `replace/`）；至少要有一種語言的國名。
- 必填：國名、顏色、類型、等級、主要文化、首都、國旗，缺了不能保存。
- 國旗（使用者回覆，見第 7 節第 4 題；簡化編輯和導入圖片可以疊加）：
  - 底紋：從底紋圖案（`gfx/coat_of_arms/patterns/`，原版 46 個）選一個，配三個顏色。〔初版做法〕顏色從紋章顏色（`common/named_colors/` 裡檔名有 coa 的，原版 35 種）選；新國家一開始是單色底紋，顏色是最接近國家顏色的紋章顏色。
  - 圖案：可以放好幾個；每個是單色徽章（`colored_emblems`，原版 868 個，各有三個顏色）、原版的紋章圖片（`textured_emblems`，原版 122 個），或導入的圖片；都可以調位置、寬高（負的就是鏡像）、旋轉。導入的圖片放滿整面，就等於整面都是圖片。
  - 〔初版做法〕單色徽章畫在圖片下面（原版國旗都這樣用，例如葡萄牙的藍色半邊在紋章下面），同一種照清單順序；寫出時也是這個順序。原版不用 `depth`，工具也不寫。
  - 〔初版做法〕工具裡的國旗照遊戲的方式合成：底紋是顏色 1，綠色通道混成顏色 2、藍色通道混成顏色 3；單色徽章是顏色 1，綠色通道混成顏色 2、紅色通道混成顏色 3，藍色通道是明暗（一半是不變），透明度照圖片。遊戲實際畫出來可能有細微差別（例如旋轉方向），要在遊戲裡確認。
  - 導入的圖片在瀏覽器等比縮放放進 768×512（國旗的 3:2 比例，原版 122 個紋章圖案中 104 個是這個尺寸），空白處透明；轉成未壓縮、有 mipmap 的 DDS（原版有 mipmap，國旗在地圖上縮小時才不會有鋸齒），放在 `gfx/coat_of_arms/textured_emblems/`（原版的紋章圖案都放這裡，用檔名引用）。〔初版做法〕檔名是 `<模組>_<圖片名稱>_<雜湊>.dds`，因為所有模組的這個資料夾是共用的。要在遊戲裡確認顯示正常。
  - 輸出：紋章 `<代碼> = { pattern = ... color1 = ... colored_emblem = { ... } textured_emblem = { ... } }`，國旗定義 `<代碼> = { flag_definition = { coa = <代碼> subject_canton = <代碼> allow_overlord_canton = yes priority = 1 } }`（成為附庸時左上角顯示宗主國旗，和原版一般國家一樣）。

## 4. 輸出（使用者回覆，見第 7 節第 1 題）

- 國家定義：`common/country_definitions/zzz_<模組>_countries.txt`（覆蓋用 `REPLACE_OR_CREATE`；新國家直接定義）。
- 國名：翻譯檔，覆蓋的寫在 `replace/`；新國家的寫在 `<模組>_countries_l_<語言>.yml`。
- 國旗（新國家）：`common/flag_definitions/zzz_<模組>_flags.txt`、`common/coat_of_arms/coat_of_arms/zzz_<模組>_coat_of_arms.txt`。
- 國家歷史、財富與識字率、人物：該國的檔案（現有國家用原檔名取代；新國家用 `<代碼小寫> - <英文國名>.txt`，沒有英文國名就用第一個填的國名，各資料夾各一個）。
- 導入的國旗圖片：`gfx/coat_of_arms/textured_emblems/<模組>_<圖片名稱>_<雜湊>.dds`。
- 領土、人口、建築、外交、條約：取代含有修改段落的原檔。
- 新的人物範本：`common/character_templates/zzz_<模組>_characters.txt`。
- 「所有國家」的開局法律：`common/history/global/zzz_<模組>_start.txt`。先寫 `every_country = { activate_law = ... }`，再接你在工具裡改過這一組的國家的 `c:TAG ?= { activate_law = ... }`，所以只有這些國家保留自己的設定（見 3.0）。

### 4.1 怎麼改寫檔案（第 1 階段）

- 〔初版做法〕改了某部分時，原檔中這部分的語句換成新的（寫在第一句的位置，其他的刪掉）；原本沒有的，寫在相關語句後面（例如額外科技接在科技等級後面），沒有相關語句就寫在段落最後。換掉的語句上的註解一起刪掉，其他語句和註解原樣保留。
- 開局法律照第 2 節：同一組的 `activate_law` 換掉；這一組原本沒有明確設定的，在最後一個 `activate_law` 或開局設定腳本後面加一行。
- 〔初版做法〕利益集團改名寫成新的翻譯鍵 `<模組>_<代碼>_<利益集團>_name`，放在 `localization/<語言>/<模組>_countries_l_<語言>.yml`；國名、形容詞、正式名稱寫在 `replace/`。
- 〔初版做法〕原本沒有歷史檔的國家（例如開局不存在的國家），改的部分寫在新檔 `common/history/countries/zzz_<模組>_countries.txt`（財富與識字率、執政黨也一樣各寫一個新檔）。
- 刪掉一個國家的修改後，它的複製檔會在下次保存時刪除，遊戲就用回原本的檔案。

### 4.2 領土、人口、建築的檔案（第 2 階段）

- `common/history/states/`：只改有變動的 `s:STATE` 段落：擁有者變了就重寫這個地域的 `create_state`，家園、宣稱變了就換掉那些語句；原本沒有段落的地域寫在 `zzz_<模組>_states.txt`。
- `common/history/pops/`、`common/history/buildings/`：只改有變動的 `region_state:TAG` 段落，寫在原本有這個地域的檔案；建築段落裡不是建築的語句（例如 `establish_cossack_host`）保留。一個地域的段落分在好幾個檔案（例如你啟用的 Tech & Res 在 `ztr_buildings.txt` 也替巴登加了建築）時，都會一起處理。
- 外交、條約：刪除提到開局不存在的國家的語句；第 3 階段的修改見 4.3。

### 4.3 外交、條約、人物的檔案（第 3 階段）

- `common/history/diplomacy/`：刪掉換掉的語句，新語句加在第一方的段落（見 3.2.3）；沒有地方放的寫在 `zzz_<模組>_diplomacy.txt`。開局不存在的國家，提到它的語句也刪掉（和第 2 階段一樣）。
- `common/history/treaties/`：刪除的條約（含 DLC 條件）從原檔刪掉；新增的寫在 `zzz_<模組>_treaties.txt`，對方開局不存在的不寫。
- `common/history/characters/`：取代這個國家的人物檔，只換 `create_character`；原本沒有人物檔的國家寫在 `zzz_<模組>_characters.txt`。同一檔的其他國家原樣保留。
- 條約名稱、新人物的名字寫在 `localization/<語言>/<模組>_countries_l_<語言>.yml`（和利益集團名稱同一個檔案）。

## 5. 限制與待驗證

- 產生的模組還沒有在遊戲裡實際載入測試；新國家的國旗（工具裡的合成、旋轉方向、徽章和圖片的上下順序）與導入圖片的顯示也要在遊戲裡確認（第 4 階段）。
- 新國家：利益集團、政黨、人物等沒有設定的部分由遊戲自動產生；會依條件改變的國名、國旗不做（見第 6 節）。
- 你的模組在遊戲啟動器裡要排在其他改開局的模組後面（例如 3371693463、2932134122），工具沒辦法替你調整載入順序。
- 國家歷史裡包在 `if` 裡的 `activate_law`，以及其他模組在全局歷史用 `every_country` 設定的法律，計算開局法律時不算進去。
- 改了某部分（例如關稅）時，同一部分的全部語句會重新寫出，所以這部分的註解會消失。
- 建築檔裡包在頂層 `if`（DLC 條件）裡的地域段落不會被修改，例如華盛頓特區的國會大廈。
- 人口、建築的改動和領土轉移有先後：你改過的清單只套用在當時的地區，見 2.3。
- 開局不存在的國家，其他國家的歷史裡用到它的地方（例如英國歷史的 `add_owned_country = c:HBC`）不會處理。
- 外交：工具不檢查協定是否合理（例如一個國家同時是兩國的附庸、附庸關係成環）；`every_subject_or_below` 等條件裡的外交語句不列出，也不會隨你的修改改變。
- 條約：只檢查格式，條款的遊戲條件（見 3.2.3）要在遊戲裡確認。
- 人物：同一個人物範本可以被好幾個國家使用，工具不阻止；新人物的肖像由遊戲隨機產生。

## 6. 初版不做

- 會依條件改變的國名與國旗（`dynamic_country_definition`、國旗的觸發條件）。
- 新增文化、宗教。
- 軍隊編制與部署、勢力集團、貿易路線、政治運動、遊說團體、外交博弈、城市中心的生產方式、AI、文化、徵兵中心、組閣（第 1 節表格下列的資料夾）：原樣保留。
- 修改現有條約的內容（只能新增、刪除，見 3.2.3）。
- 人物的外觀（DNA）與肖像。
- 開局歷史裡的日誌、變數、修正、公司：只當腳本原樣保留。
